Privacy policy

Last updated: 24 November 2026

  • Drive Backup is a personal tool used only by its owner.
  • It requests only the drive.file scope, so it can access only the Google Drive files it created itself.
  • It uses this access to upload, read, list and delete its own encrypted backup files.
  • It does not collect data about other people, does not share or sell data, and uses no analytics or advertising.
  • The Google access token is stored only on the owner's server. Access can be revoked at any time in the Google Account settings.
